# 2R Informática — Landing Page

Landing page institucional responsiva desenvolvida como projeto de portfólio para uma empresa conceitual de suporte, manutenção e infraestrutura de TI.

🔗 **Projeto publicado:** https://ruan2r.github.io/P12-LANDING-PAGE-2R/

## Sobre o projeto

A proposta foi criar uma presença digital para uma empresa de tecnologia com foco em atendimento técnico, manutenção de computadores, redes, infraestrutura e suporte para empresas e residências.

O projeto foi construído do zero com foco em:

- comunicação clara e objetiva;
- identidade visual própria;
- hierarquia visual e experiência do usuário;
- responsividade em desktop, tablet e mobile;
- acessibilidade e navegação por teclado;
- componentes visuais conceituais para representar serviços de TI;
- base preparada para uma futura integração com um sistema de O.S./chamados.

> **Importante:** os painéis, indicadores e interfaces exibidos na página são recursos conceituais de apresentação. Eles não representam um sistema real de monitoramento conectado à infraestrutura de um cliente.

## Funcionalidades

- Navegação por âncoras entre as seções.
- Header fixo com navegação desktop.
- Menu mobile com abertura/fechamento e suporte a `Esc`.
- Scroll suave.
- Estados de `hover` e `focus`.
- Layout responsivo.
- Formulário de contato com validação no frontend.
- Feedback visual após o envio do formulário.
- Tratamento para usuários de teclado e `prefers-reduced-motion`.
- SEO básico e metadados para compartilhamento.
- Favicon e identidade visual baseada na marca 2R Informática.

## Decisões de projeto

Durante o desenvolvimento, o projeto passou por várias rodadas de refinamento visual e de conteúdo.

Entre as principais decisões:

### Comunicação
Priorização de textos objetivos e próximos da linguagem de uma empresa real, evitando excesso de slogans e frases genéricas.

### Identidade visual
Uso de fundo escuro, tons de azul/ciano e contrastes controlados para criar uma aparência técnica sem deixar a interface visualmente pesada.

### Interface conceitual
Os mockups foram usados para comunicar serviços e cenários de TI sem transformar a landing page em um suposto sistema de monitoramento real.

### Responsividade
Desktop e mobile possuem a mesma informação e estrutura semântica, com adaptações específicas de espaçamento, empilhamento e dimensionamento para telas menores.

### Clareza visual
Evitei o uso excessivo de numeração e elementos decorativos repetitivos. A hierarquia é construída principalmente com tipografia, espaçamento, ícones e composição.
