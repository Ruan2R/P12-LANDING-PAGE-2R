# 2R Informática — Landing Page

Landing page institucional/conceitual da 2R Informática, construída como projeto de portfólio.

## Stack
- HTML5 semântico
- CSS3 responsivo
- JavaScript vanilla
- SVG inline para elementos visuais

## Estrutura atual
- Navbar responsiva + logo oficial
- Hero com interface conceitual de tecnologia
- Serviços
- Soluções para empresas
- Sobre + diferenciais
- Processo de atendimento
- Seção de contato com formulário demonstrativo
- Footer

## Próximos passos
- Revisão visual e responsividade
- Refinamento de microinterações
- SEO/performance
- Publicação do case
- Evolução futura para portal/sistema de O.S. e chamados

> Projeto visual/conceitual de portfólio. As interfaces, métricas e conteúdos de demonstração não representam uma operação real.
