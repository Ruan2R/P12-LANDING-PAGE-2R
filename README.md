# 2R Informática — Landing Page

Landing page institucional/conceitual da 2R Informática, construída como projeto de portfólio.

## Stack
- HTML5 semântico
- CSS3 responsivo
- JavaScript vanilla
- SVG inline para elementos visuais

## Estrutura atual
- Navbar responsiva + logo oficial
- Hero com interface conceitual de tecnologia
- Serviços
- Soluções para empresas
- Sobre + diferenciais
- Processo de atendimento
- Seção de contato com formulário demonstrativo
- Footer

## Próximos passos
- Revisão visual e responsividade
- Refinamento de microinterações
- SEO/performance
- Publicação do case
- Evolução futura para portal/sistema de O.S. e chamados

> Projeto visual/conceitual de portfólio. As interfaces, métricas e conteúdos de demonstração não representam uma operação real.


## Revisão visual V1.8
- Grade de serviços reorganizada para 6 cards equilibrados, removendo a composição com um card isolado na última linha.
- Removidos os indicadores “02 / 04” e “03 / 04”, que sugeriam uma sequência/carrossel que não existe.
- Refinada a assinatura visual do bloco Sobre, evitando uma data decorativa e mantendo o foco no conceito.
- Título de diferenciais revisado para uma mensagem mais direta: “Técnica no que importa. Simples no que entrega.”

## Revisão visual V2.2
- Copy do bloco Sobre revisada para uma linguagem mais direta e profissional.
- Headline dos diferenciais ajustada para evitar tom excessivamente publicitário.
- CTA e textos da seção de contato revisados para reduzir repetição.
- Footer redesenhado apenas na tipografia: corpo maior, melhor contraste, títulos em caixa normal e pesos mais leves.
